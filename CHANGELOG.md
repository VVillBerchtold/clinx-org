# Changelog

## Unreleased

- The site is public. `PREVIEW` is `false`: the Draft tags are gone, search engines may list the pages, and `sitemap.xml` is written. The wording was approved by the owner on 12 November 2026.
- The repository reads in plain words: the README says what the site is, where its numbers come from and where each part lives, with a table of the site's promises and the code that keeps each one. The detail moved to `docs/`, one topic to a page (how the site is built, how figures and names are written, the checks, the monthly refresh, publishing and the contact form), and `src/lib/`, `scripts/` and `worker/` each have a short note. On the Data page the three repository names become links when the site goes public.
- Getting ready to go public, with the site still a private preview: one setting (`PREVIEW` in `src/lib/site.ts`) now switches the Draft tags, `robots.txt` and the pages' "do not list" tags together, and a public build writes `sitemap.xml` from the pages it built. Every page names its public address and carries a title, description and picture for link previews (`public/brand/share-card.png`). "Page not found" and the contact form's answer pages always ask not to be listed. The built-site check fails if these disagree.
- Accessibility fixes from a Lighthouse and axe-core pass over every page kind (light and dark, phone and desktop): each state tile on the map now carries its letters in its link name ("VT, Vermont: open the scorecard") and the map is a labelled group, not an image, so its links are reachable; the "Founder" label on About is readable on the dark panel in the light theme (`--band-accent`); a table that scrolls sideways (Methods, Data) can take keyboard focus so the arrow keys scroll it.
- Drug pages and the five-largest list on a filing page: a filer's own drug names are written one way (`src/lib/filed-drug-display.ts`): capitals, spaces, unit names, a zero before a bare decimal point and commas in long numbers ("ABILIFY MAINT 400MG KIT" reads "Abilify Maint 400 mg kit"). No word is replaced, spelled out or dropped; shorthand and unknown short words stay as typed. The dataset, the downloads and the filing keep each name as typed, and the search reads both. Labels beside a name no longer say "as filed" ("Drug", "Name in the filing", "Named ... by"). A test checks every drug name in the dataset keeps its words and number values.
- Figures and names are written one standard way on the pages; nothing in the data changes. Filed amounts and claim counts get commas between thousands, and an amount filed with one decimal place is written with two (`drawFigure`, `drawFiguresInText` in `src/lib/money.ts`); the notes beside a difference get the same commas. The FDA directory's text is written one way (`src/lib/fda-display.ts`): capitals of names, ingredients and labelers, strengths (".5 mg/1" reads "0.5 mg") and unit names. The filing PDF, the dataset files, the names file and the downloads keep every value as filed or as listed. A filer's own drug name stays word for word.
- Home page, Minnesota: the card now names the form like the other cards and shows the report's net 340B revenue as two bars on a dollar scale ($1.15 billion for the entities the report names, $123.8 million for all others, of $1.28 billion statewide), with the percentages the report prints. The build stops if the two parts do not add up to the printed total.
- The monthly refresh now brings the FDA drug names up to date: it downloads the National Drug Code Directory, rebuilds `reference/fda-ndc/names.csv` and writes a report of every name added, changed or dropped. A name the directory later drops is kept with the day it was last listed (`listed_on`; `fda_listed_on` in the download), and the row says so. An unusual amount of change, or a failed download, fails the refresh and nothing is published.
- Each filer's drug page: under a row's code, the name the FDA's National Drug Code Directory lists for it ("Listed by the FDA as ..."), with ingredient, strength, form and labeler; the search finds them. The name as filed stays the row's name, and a note on the page says the line is not part of the filing.
- Rhode Island drug page of all filings: where the FDA's National Drug Code Directory lists a drug code, the page shows the FDA's name, ingredient, strength, form and labeler, and the search finds them; each filer's own wording stays beside it. The download gains seven `fda_` fields. Codes the directory does not list keep the name as filed and say so. The names are held in `reference/fda-ndc/` and built by `scripts/reference/build-fda-ndc.mjs`.
- Getting around long pages: the section links at the head of a page are now a contents list; a slim bar follows the reader down the page, names the section being read and opens a menu of all sections; a "Back to top" button on every page; previous and next links at the end of each filing page and each filer's drug page.
- Structure of the site: pages, data sync, build-time chart, safety scan, CI. Draft; not public.
- New look across every page (self-hosted fonts, light and dark themes, tick meter, tile map of the states).
- Scorecard is now by state: a states page, a page per state and a page per filing.
- A drug page for each Rhode Island filing (Schedule G): every row as filed, searchable, with a filter, an order and a sum of the amounts shown. A count of 1 to 5 is never shown.
- Rhode Island: one page of the drug rows of all filings side by side, by drug code (`/scorecard/ri/drugs/`), with search, a filter by filer, an order, and each filer's row linked to its page of the filing; and one download of all the rows (`/data/drug-rows-ri-2025.csv`). Rows are grouped only on a code filed as one 11-digit NDC. An amount added across filers is marked as added by the site; claims added across filers read "at least" where a count is left out.
- Tables: larger text and taller rows; every bar sits in a track of one length per table; the reporting basis and a normalized name sit under the name; on a phone the wide tables stack row by row with sort buttons, and nothing scrolls sideways. The data dictionary's column names no longer break mid-word.
- Home page is state-neutral: the map, the states in the scorecard, and where each state with a reporting law stands (read from each law on 11 November 2026).
- New pages: About, Products, Privacy and security. The demo and article were redesigned.
- NOTICE.md: font licences and the names and logos that the MIT licence does not cover.
